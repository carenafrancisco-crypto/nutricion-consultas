# Lecciones

## 2026-10-30 - Indicaciones clinicas de Francisco sin evidencia incontestable
- Regla: nunca borrar, degradar ni sacar del producto una indicacion de Francisco por falta de evidencia. Se conserva y se marca "indicacion clinica de Francisco - evidencia a buscar". La evidencia se busca despues.
- Ejemplo: merencenas / cena temprana y desayuno tarde. Para dispepsia e hiperinsulinemia son indicacion firme ("sagrada").
- Precision (2026-10-30): conservar no es presentar como eficacia demostrada. Clasificar: IF indicacion de Francisco / E3 hipotesis fisiologica / E2 respaldo parcial / E1 eficacia demostrada. IF sin E1 = uso individualizado, no regla universal.

## 2026-10-30 - Material usable antes que perfecto
